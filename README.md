# <img width="25" height="25" alt="image" src="https://github.com/user-attachments/assets/a8fef7e6-abfa-4a60-81c9-b5a96ce47fc9" /> Looper

> 2025.04 ~ 2025.07 (Kakaotech Bootcamp)

**Looper는 혁신적인 AI 기반 루틴 관리 서비스로, 반복적인 일상에 효율을 추구하는 모든 사람들을 위해 개발되었습니다.**    

단순한 캘린더를 넘어, 메모·회의록 속 중요한 정보를 자동 분석해 일정으로 변환하고, 운동이나 학습 같은 프로젝트도 단계별 루틴으로 세분화해 드립니다.

[자세한 내용은 프로젝트 위키를 참조해주세요](https://github.com/100-hours-a-week/11-ellu-fe/wiki)

## 🚀 Tech Stack

| 카테고리       | 기술 스택                                   |
|----------------|----------------------------------------------|
| **기본 프레임워크** | React 19, Next.js 15                         |
| **언어 & 문법**    | TypeScript                                   |
| **상태 관리**     | Zustand, TanStack Query                      |
| **스타일링**      | CSS Modules, MUI (Material UI)               |
| **캘린더 UI**     | FullCalendar                                 |
| **실시간 처리**   | WebSocket, Server-Sent Events                |
| **테스트**        | Jest                                          |

<br>

## 🌈 Running the app

```
# 개발 서버 실행 (Turbopack 활성화)
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행  
npm run start

# 테스트 실행
npm run test          
npm run test:watch    
npm run test:coverage # 커버리지 포함
```
